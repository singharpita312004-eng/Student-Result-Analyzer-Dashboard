# Student Result Analyzer Dashboard

## Overview
This project analyzes student performance using Python and Pandas. It generates insights and visualizations such as subject averages, pass/fail ratio, top performers, and gender-wise average marks.

## Features
- Student performance analysis
- Subject-wise average marks
- Gender-wise average comparison
- Pass vs Fail analysis
- Top 10 students
- Data visualization using Matplotlib

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Dataset
The dataset is a sample student result dataset created for learning and project purposes.
